# Codici sorgente incorporati

In questa sezione puoi consultare il codice sorgente incorporato nelle varie versioni di **miniOS** pubblicate sul sito.

---

## Versioni disponibili

* [Versione 1.0](v1.0/)

---

## Informazioni

Il **codice sorgente incorporato** corrisponde ai file inclusi nella versione di miniOS pubblicata sul sito.

Se invece desideri consultare il codice sorgente completo del progetto, visita la cartella [`src`](https://github.com/DeMENIGECO/miniOS/tree/main/src) nel repository GitHub.

> **Nota** \
> Per motivi di praticità e di visualizzazione, alcuni file potrebbero non essere mostrati direttamente sul sito. In questi casi saranno disponibili come download oppure tramite un collegamento al repository GitHub.
