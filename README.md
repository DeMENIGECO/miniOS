**miniOS** è un mini sistema operativo scritto interamente in **HTML, CSS e JavaScript**, contenuto in un singolo file.  
Non richiede installazione, non usa dipendenze esterne e funziona su qualsiasi browser moderno.

🌐 **Sito ufficiale:** https://demenigeco.github.io/miniOS  
📦 **Download:** https://demenigeco.github.io/miniOS/download  
🧪 **Webtest:** https://demenigeco.github.io/miniOS/webtest/  
🗂️ **Codice sorgente (HTML build):** https://demenigeco.github.io/miniOS/src/

---

## ✨ Caratteristiche principali

- **Un solo file HTML**  
  Tutto il sistema operativo è contenuto in un unico file `.html`.

- **Funziona ovunque**  
  Basta un browser moderno. Nessuna installazione, nessun setup.

- **Interfaccia stile OS**  
  Finestre, pulsanti, app simulate (Explorer, Terminale, Impostazioni, Giochi, Python).

- **Leggerissimo**  
  Si apre in un istante, anche su dispositivi molto lenti.

- **Perfetto per imparare**  
  Ideale per chi vuole studiare HTML, CSS e JavaScript in modo pratico.

- **Open Source**  
  Codice disponibile sia su GitHub che nella sezione `/src/` del sito.

## 🛠️ Come modificare miniOS

1. Scarica il file HTML della build.  
2. Aprilo con un editor di testo (VS Code, Notepad++, ecc.).  
3. Modifica liberamente HTML, CSS e JavaScript.  
4. Salva e apri il file nel browser.

miniOS è progettato per essere **hackabile** e facile da estendere.
